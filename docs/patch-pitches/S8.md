# S8 Patch Pitch

## Current Shape

GridPulse is a Gin JWT app with a public admin route, expvar env exposure,
weak-hash-plus-hash-leak path, public SQLi, and weak-secret JWT forgery.

## Main Normalization Issues

- `flag_1` is too cheap because it is fully unauthenticated.
- `flag_3` again advertises a hash leak that is not actually required.
- `flag_4` is easier than the authenticated SQLi flows elsewhere.
- `flag_5` is valuable and distinctive, but it sits next to several cheaper
  flags.

## Recommended Design Changes

- Change the access-control bug to low-privilege authenticated access without
  role enforcement.
- Make the weak-hash flag require profile leak, crack, and pivot.
- Gate the SQLi behind an authenticated low-privilege token.
- Keep the JWT-forgery centerpiece for the login/token-security slot.

## Difficulty Intent

Removing the unauthenticated shortcuts should raise difficulty while preserving
the most valuable Gin-specific learning signal.

## Pitch

S8 has the best framework-specific auth slot in the Go/Rust cluster, but it is
less uniform than it looks because several other flags are too public and too
cheap. Keeping the JWT forgery centerpiece while converting the easier flags
into authenticated pivots would make S8 harder, cleaner, and much easier to
compare against S7 and S9.
