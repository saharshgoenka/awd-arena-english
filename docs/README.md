# Documentation Index

This directory holds project reports and operational guides that are too
detailed for the root README.

## Start Here

- `../README.md`: project overview, quick start, clean/full run ledger, and
  common UI/API workflows.
- `../AGENTS.md`: handoff guide for new coding-agent chats.
- `../CHANGELOG.md`: current repo baseline and major change history.
- `sample-rounds.md`: how to launch one S1-S9 sample without writing raw API
  payloads.

## Benchmark And Meeting Reports

- `meeting-scores-image-stats-2026-06-16.md`: meeting-ready snapshot of known
  sample scores, image metadata, and clean-run status.
- `results.md`: historical research notebook for the original benchmark plan,
  including cost probes, phase notes, and older run analysis.
- `../RESEARCH_PLAN.md`: research questions, benchmark phases, and original
  experimental design.

## Component Documentation

- `../referee-engine/README.md`: FastAPI referee API overview.
- `../target-image/README.md`: default target image notes.
- `../target-image/TESTING.md`: target-image testing notes.

## Where New Docs Should Go

- Put meeting artifacts, run ledgers, and analysis reports in `docs/`.
- Put scenario authoring prompts in `prompts/`.
- Put runnable benchmark configs in `bench/`.
- Keep one-off local scratch files out of git unless they are useful to future
  runs.
